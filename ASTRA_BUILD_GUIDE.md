# Shijil TC — Astra Portfolio Build Guide

## Recommended WordPress setup
1. Install **Astra** as the WordPress theme.
2. Use the WordPress block editor (Gutenberg) or Spectra blocks.
3. Create a full-width page called **Portfolio**.
4. Set the page layout to **Astra Full Width / No Sidebar**.
5. Add the sections in this order:
   - Hero
   - About
   - Selected Work
   - Expertise
   - Experience & Education
   - International Project Exposure
   - Contact
6. Use the supplied `portfolio.html` as the visual/content reference.

## Astra design direction
- Background: warm off-white
- Surface: cream
- Text: charcoal
- Accent: moss green
- Secondary accent: ochre
- Typography: Space Grotesk headings + Inter body + IBM Plex Mono labels
- Use generous whitespace and thin borders.
- Keep project cards clean and technical rather than flashy.

Each case study should contain:
- Problem / objective
- Study area
- Data sources
- Methodology
- GIS workflow diagram
- Maps / screenshots
- Key result
- Tools
- Your contribution
- Limitations / next step

## Important
Do not publish confidential client data, exact project coordinates, proprietary datasets, internal methodologies, or sensitive project documents. Use generalized project descriptions and sanitized screenshots where required.

## Before launch
Replace the LinkedIn and GitHub placeholders with your real profile links, add your best map screenshots, and create 5–8 polished case studies rather than uploading every internal work product.
